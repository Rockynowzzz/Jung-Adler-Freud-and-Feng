# 维度6：荣格的人物时间线

> 本文件梳理荣格从出生(1875年7月26日，凯斯维尔)到去世(1961年6月6日，苏黎世)的完整时间线，含关键里程碑、思想转折点、世界观演化。
> 标注说明：【一手】= 荣格本人原话/口述；【二手】= 他人记录或评述。

---

## 完整时间线

### 早年（1875-1900）

| 年份 | 事件 | 来源 |
|------|------|------|
| 1875年7月26日 | **出生**。卡尔·古斯塔夫·荣格生于瑞士图尔高州凯斯维尔(Kesswil)。父亲约翰·保罗·荣格是改革宗新教牧师；母亲艾米莉·普莱斯维克。两人都是各自家庭的第13个孩子(被视为吉兆)。父亲最终成为精神病院的牧师。 | 【二手：carl-jung.net；robertboynton.com 引 Bair】 |
| 1875-1886 | 在乡村长大。内向、孤独的男孩，有双重人格("一个笨拙、尴尬、数学笨蛋的男孩生活在19世纪末的当下"和"一个生活在18世纪的老人，穿高扣鞋、戴扑粉假发、驾精致马车")。童年参与表姐主持的家庭降神会；母亲(分裂人格的妄想型歇斯底里患者)相信房子闹鬼。有神秘异象，包括一个上帝在教堂上排泄的异象。 | 【二手：robertboynton.com 引 Bair，可信度：高】 |
| 约1886 | 11岁时突然的自我意识觉醒。BBC访谈自述："在我第十一年，我突然在上学路上从雾中走出。就像我一直在雾中走，然后我走了出来，我知道'我是。我是我所是。'然后我想，'但我之前是什么？'然后发现我一直在雾中，不知道如何将自己与事物区分。我只是事物中之一。"这个自我揭示与认识到父亲的不可靠(约11-12岁)紧密相连。白天不怕母亲，夜里怕。 | 【一手：BBC访谈；MDR pp.32f./44f.】 |
| 1895 | 进入巴塞尔大学学习科学与医学。原本想成为考古学家(亚述学、埃及学)，但没钱，学业太贵。第二选择是自然科学。 | 【二手：carl-jung.net；一手：BBC访谈】 |
| 1896 | 荣格的父亲去世。 | 【二手：carl-jung.net，可信度：中高】 |
| 1900 | 以医学博士(M.D.)从巴塞尔大学毕业，被任命为苏黎世布尔格赫尔茨利精神病医院的助理，在 Eugen Bleuler 教授麾下。这一决定源于翻到一本精神病学教科书导言中"精神病是人格失调"这句话——"那一瞬间我看到我必须当精神病患者学家。我的心在那一刻狂跳。" | 【二手：carl-jung.net；一手：BBC访谈】 |

### 布尔格赫尔茨利时期与弗洛伊德结盟（1900-1913）

| 年份 | 事件 | 来源 |
|------|------|------|
| 1900-1909 | 在布尔格赫尔茨利精神病院工作。发展了词联想实验，证明了**情调复合体**(feeling-toned complexes)——扭曲意识思想的潜意识观念簇。使他在欧美成名。 | 【二手：renodus.com，可信度：高】 |
| 1902 | 在苏黎世大学获博士学位，博士论文《论所谓神秘现象的心理学与病理学》——对超自然现象持同情态度。 | 【二手：robertboynton.com；carl-jung.net，可信度：高】 |
| 1903 | 与艾玛·劳申巴赫结婚。她是瑞士第二富有的女继承人。经济独立在智识上解放了荣格。两人育有五个孩子。 | 【二手：carl-jung.net；robertboynton.com，可信度：高】 |
| 1905-1913 | 在苏黎世大学任精神病学讲师。 | 【二手：carl-jung.net；speakingofjung.com，可信度：中高】 |
| 1906 | 开始与弗洛伊德通信。发表关于词联想的著作。 | 【二手：carl-jung.net，可信度：中高】 |
| **1907** | **与弗洛伊德首次会面**。荣格将自己1906年的《早发性痴呆心理学》(Psychology of Dementia Praecox)寄给弗洛伊德，赴维也纳与之长谈两周。"那场漫长而深入的对话之后，一切定下来了"，很快发展为私人友谊。弗洛伊德将荣格封为"科学上的儿子和继承人"，寻求一位外邦人(gentile)来捍卫他的"犹太科学"。弗洛伊德后来(1910年)要求荣格"承诺永不放弃性理论……把它变成教条，一个不可动摇的堡垒"。荣格问"抵御什么？"，弗洛伊德答"抵御神秘主义的黑泥潮"。 | 【二手：carl-jung.net；robertboynton.com，可信度：高；一手：BBC访谈】 |
| 1908 | 第一个孩子出生(后共有五个)。 | 【二手：speakingofjung.com，可信度：中高】 |
| 1909 | 辞去布尔格赫尔茨利职务(因私人咨询和心理治疗负担过重)。与弗洛伊德一起访美(克拉克大学)。在库斯纳赫特开设私人精神分析诊所，热情经营至去世。 | 【二手：carl-jung.net；cgjung-museum.ch，可信度：中高】 |
| 1910 | 当选国际精神分析协会主席。 | 【二手：carl-jung.net，可信度：中高】 |
| 1911 | 国际精神分析学会成立，荣格任主席至1913年。1911-1913年逐渐脱离弗洛伊德。 | 【二手：cgjung-museum.ch，可信度：中高】 |
| **1912** | **宣布科学上独立于弗洛伊德**，出版《转化的象征》(Symbols of Transformation, CW 5)——通过神话而非性理论重新诠释患者的幻想。这是与弗洛伊德决裂的"最后原因"，但它有漫长的准备。"从一开始我就有 reservatio mentalis(心理保留)。" | 【二手：carl-jung.net；一手：BBC访谈，可信度：中高-高】 |
| **1913** | **与弗洛伊德最终决裂**。辞去国际精神分析协会主席。"其余是沉默"，荣格写道。 | 【二手：carl-jung.net；robertboynton.com，可信度：高】 |

**思想转折点（1907-1913）**：与弗洛伊德的结盟和决裂是荣格一生最关键的转折。核心分歧从性理论扩展到"人的历史条件"——"我们不是今天或昨天的；我们有着巨大的年龄"。从纯个人取向(弗洛伊德)到集体/历史取向(荣格)的转向，奠定了集体潜意识概念的基础。荣格后来将分歧重新框架为类型学差异(外倾 vs 内倾)。【二手：renodus.com；一手：BBC访谈】

### "与潜意识的对抗"——红书时期（1913-约1930）

| 年份 | 事件 | 来源 |
|------|------|------|
| **1913-1917** | **与潜意识的对抗**(confrontation with the unconscious)。与弗洛伊德决裂后，荣格经历了一段受控的、刻意与从自身心理深处升起的意象、声音和形象进行持续接触的时期。出现自主声音和形象：费勒蒙(智慧老人)、莎乐美、以利亚、红色者。BBC访谈自述："我有相当多这类经验……甚至去华盛顿研究黑人(精神病院)。"这些经验记录在《红书》中。 | 【二手：thalira.com；renodus.com；一手：BBC访谈】 |
| 1914-约1930 | **《红书》(Liber Novus)创作**。约16年间持续记录。含与内在形象的对话、精工书法、细致画作。荣格视其为所有后来理论著作的基础个人经验。在世时从未授权出版——保存在家族银行金库中，直到2009年。 | 【二手：thalira.com；ontologicalatlas.com；carljungdepthpsychologysite.blog】 |
| 1914起 | 维持与妻子艾玛和前患者托妮·沃尔夫的公开"非 orthodox 情感三角"，称沃尔夫为"另一个妻子"。 | 【二手：robertboynton.com 引 Bair，可信度：高】 |
| 1916 | 费勒蒙作为内在导师出现。荣格为费勒蒙画像。费勒蒙成为其成熟理论中"智慧老人"原型的原型。 | 【二手：renodus.com，可信度：高】 |
| 1917 | 出版《潜意识过程的心理学》(Die Psychologie der unbewussten Prozesse)。 | 【二手：carl-jung.net，可信度：中高】 |
| 1918 | 预警德国："金发野兽在地下牢笼中躁动……威胁我们以将产生毁灭性后果的爆发。" | 【一手，经 theeraofathena.wordpress.com 引 Welsh, Hannah, Briner 1947，可信度：中高】 |
| **1919** | **首次使用"原型"(archetype)一词**(在《本能与潜意识》Instinct und Unbewusstes中)。 | 【二手：carl-jung.net，可信度：中高】 |

**思想转折点（1913-1919）**：这是荣格从弗洛伊德学派精神分析师到分析心理学创始人的转化期。《红书》的经验直接产生了：主动想象技术、原型概念(费勒蒙=智慧老人、莎乐美=阿尼玛)、个性化进程理论。从弗洛伊德的个人潜意识到集体潜意识的范式转换在此完成。【二手：renodus.com；thalira.com】

### 成熟期——理论建构与世界旅行（1921-1939）

| 年份 | 事件 | 来源 |
|------|------|------|
| **1921** | **出版《心理类型》(Psychological Types, CW 6)**。引入内倾/外倾区分与四种功能(思维、情感、感觉、直觉)。后成为 MBTI 的基础。 | 【二手：carl-jung.net；thalira.com，可信度：中高】 |
| 1922 | 在波林根买地(圣迈因拉德地区，旧教会土地，原属圣加仑修道院)。 | 【一手：MDR，可信度：中高】 |
| **1923** | **开始建造波林根塔楼**。在母亲去世两个月后开始第一个圆形塔。这是个性化的物化。同年访问北美普韦布洛印第安人。 | 【二手：carl-jung.net；一手：MDR，可信度：中高】 |
| 1923(冬)-1924(春) | 独自在波林根的第一个塔中。经历水壶"多声部音乐"的异象和"数百个穿暗色衣服的农民男孩围绕塔楼"的梦(后从17世纪卢塞恩编年史中找到平行——沃坦在皮拉图斯山上至今施魔法)。 | 【一手：MDR，可信度：中高】 |
| 1925 | 东非埃尔贡山埃尔贡尼人的研究旅行。 | 【二手：carl-jung.net，可信度：中高】 |
| 1926 | 做"关键"的梦：在战时意大利前线被"困在17世纪"。近30年后完成炼金术研究《神秘结合》时"出来"。引导他研究炼金术。 | 【一手：MDR，经 jungiancenter.org，可信度：中高】 |
| **1927** | 塔楼增建中心结构和塔式附属(第二阶段)。 | 【一手：MDR，可信度：中高】 |
| 1928 | 卫礼贤(Richard Wilhelm)寄来中国炼金术文本《太乙金华宗旨》译本，荣格被"搅动去更仔细地认识炼金术文本"。开始30余年的炼金术研究。加入国际普通医学心理治疗学会(IGMSP)。 | 【一手：MDR，经 jungiancenter.org；二手：theeraofathena.wordpress.com，可信度：中高】 |
| **1929** | 出版对道家文本《太乙金华宗旨》的评论。将道家"内丹"与"个性化进程"并置对读。 | 【二手：carl-jung.net，可信度：中高】 |
| **1930** | 任IGMSP副会长。 | 【二手：theeraofathena.wordpress.com，可信度：中高】 |
| **1931** | 塔楼塔式附属被扩展，增加退隐室(第三阶段)。出版《当代灵魂问题》(Seelenprobleme der Gegenwart)。 | 【一手：MDR；二手：carl-jung.net，可信度：中高】 |
| 1932-1940 | 在苏黎世联邦理工学院任心理学教授。 | 【二手：carl-jung.net，可信度：中高】 |
| **1933** | **接受IGMSP主席职位**——因为他是瑞士人(中立国)，政治位置更好。期刊重组为国际版(荣格编辑)和德文版(戈林控制)。在科隆讲座中警告集体压抑个人。同年《现代人在寻求灵魂》(Modern Man in Search of a Soul)出版。 | 【二手：theeraofathena.wordpress.com；carl-jung.net，可信度：中高】 |
| 1934 | 出版《灵魂的现实》(Wirklichkeit der Seele)。开始尼采《查拉图斯特拉》系列研讨会(至1939年)。任国际医学心理治疗学会主席(至1939年)。在《Zentralblatt》编辑语中写弗洛伊德和阿德勒"创造了特定的犹太教义，完全不能满足日耳曼心态"——引发反犹太主义指控。 | 【二手：carl-jung.net；freudonthedock.wordpress.com，可信度：中高】 |
| **1935** | 塔楼增建庭院和湖畔凉廊(第四阶段)，形成四元性。伦敦塔维斯托克讲座"分析心理学"。 | 【一手：MDR；二手：carl-jung.net，可信度：中高】 |
| 1936 | 将纳粹运动解读为"沃坦"(Wotan)原型爆发(论文)。兴奋减弱，认出希特勒和纳粹运动的恶魔面。期待恶面转向其反面(原型二元性)。 | 【二手：theeraofathena.wordpress.com，可信度：中高】 |
| **1937** | 耶鲁大学 Terry 讲座"心理学与宗教"(后出版为《心理学与宗教》1938年)。印度研究旅行。在耶鲁暗示德国在投射自身状况于邻国。 | 【二手：carl-jung.net；theeraofathena.wordpress.com，可信度：中高】 |
| 1939 | 弗洛伊德去世后，荣格谈论弗洛伊德，未提宗教/种族差异。辞去IGMSP主席(1934-1939)。 | 【二手：theeraofathena.wordpress.com；carl-jung.net，可信度：中高】 |
| **1940** | 塔楼相关德文出版物被压制，荣格上了纳粹"黑名单"。法国被入侵后，盖世太保销毁了他的法文译本。被升为IGMSP"名誉主席"挂名位置，任至1940年。 | 【二手：theeraofathena.wordpress.com，可信度：中高】 |

**思想转折点（1921-1940）**：这一时期是荣格理论系统化与世界旅行的并行期。旅行(非洲、印度、普韦布洛)验证了集体潜意识的跨文化普遍性。炼金术研究将心理学与西方神秘传统连接。政治上，IGMSP决策成为其最大的争议遗产。纳粹解读("沃坦")显示了原型理论应用于当代政治的解释力与误判风险。【综合各源】

### 战时与晚年——炼金术高峰与全球声望（1941-1961）

| 年份 | 事件 | 来源 |
|------|------|------|
| 1941 | 出版与凯雷尼(Karl Kerényi)合著的《神话学科学论文》(Essays on a Science of Mythology)。开始写作《神秘结合》(Mysterium Coniunctionis, 至1954年)。 | 【二手：carl-jung.net，可信度：中高】 |
| 1942 | Eranos 会议讲座"墨丘利精灵"(The Spirit Mercurius)。帕拉塞尔苏斯逝世500周年纪念讲座"作为精神现象的帕拉塞尔苏斯"。 | 【二手：jungiancenter.org，可信度：中高】 |
| 约1943-1945 | 作为"488号特工"为战略情报局(OSS)间谍招募者艾伦·杜勒斯简报纳粹领袖心理。意见"在该机构的行动政策中占据重要位置"。 | 【二手：robertboynton.com 引 Bair，可信度：高】 |
| 1944-1945 | 任巴塞尔大学医学心理学教授。患重病(心脏病发作/栓塞)。Esther Harding 记录："在他整个病程中，他告诉我们，想法不断涌上来，甚至在谵妄中，他仍在试图评估和记录。" | 【二手：carl-jung.net；C.G. Jung Speaking pp.171-179，可信度：中高】 |
| 1945 | 荣格关于说服德国公众接受战败的想法被最高盟军司令艾森豪威尔阅读。出版《灾难之后》(Nach der Katastrofe)。 | 【二手：robertboynton.com；carl-jung.net，可信度：高-中高】 |
| 1948 | **苏黎世C.G.荣格学院成立**。 | 【二手：carl-jung.net，可信度：中高】 |
| **1950** | 出版《伊雍——自性现象学研究》(Aion)。在波林根制作石碑(75岁生日)，刻拉丁文、希腊文和炼金术引文。 | 【二手：carl-jung.net；一手：MDR，可信度：中高】 |

## 世界观演化总结

荣格的世界观演化可概括为四个阶段：

### 第一阶段：临床经验主义（1900-1907）
在布尔格赫尔茨利的精神病学家。以词联想实验和情调复合体建立早期声誉。经验主义取向，受 Janet 和弗洛伊德影响。世界观仍可纳入主流精神病学框架。【二手：renodus.com】

### 第二阶段：弗洛伊德结盟与决裂（1907-1913）
弗洛伊德的"王储"时期。逐渐发展 reservatio mentalis。从纯个人取向到历史/集体取向的转向开始。1912年《转化的象征》标志着与弗洛伊德性理论的公开决裂。世界观从生物还原论转向象征/历史取向。【一手：BBC访谈；二手：renodus.com】

### 第三阶段：与潜意识的对抗——原型理论的诞生（1913-1930）
最关键的转化期。《红书》的私人经验直接产生原型理论、个性化进程、主动想象技术。从弗洛伊德个人潜意识到集体潜意识的范式转换完成。世界观从临床精神病学转向深度心理学与比较神话学/宗教学的交叉。【二手：thalira.com；renodus.com】

### 第四阶段：系统化与全球传播（1930-1961）
理论系统化(《文集》20卷)、炼金术研究(1928-1954)、世界旅行验证(非洲、印度)、政治应用与争议(IGMSP、OSS)、全球声望(BBC访谈)。世界观成熟为"历史比较心理学"——将心理学、炼金术、比较宗教、东方哲学整合为统一体系。晚年自我叙述(《回忆·梦·思考》)将一生框架为"潜意识自我实现的故事"。【二手：renodus.com；thalira.com】
