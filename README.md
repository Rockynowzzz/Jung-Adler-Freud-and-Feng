# 弗洛伊德 · 荣格 · 阿德勒 · 峰哥

> 三位百年前决裂的心理学巨头，和弗洛伊峰，被塞进了同一个仓库。

---

## 这到底是什么

1911 年，阿德勒跟弗洛伊德吵翻，带 9 个人摔门走人。

1913 年，荣格也跟弗洛伊德决裂，通信中断，从此老死不相往来。

2026 年，有人把这三个决裂了一个多世纪的老头儿，加上一个把弗洛伊德简化成"一切精神问题源于性压抑"的中文互联网博主，放在了同一张桌子上。

**这桌子就这么支起来了。**

这不是学术综述，不是心理咨询，是一个思维实验：如果让这四个人坐在同一间屋子里，面对同一个问题，他们会怎么说？会吵成什么样？谁会拍桌子？谁会冷笑？谁会嘿嘿一声"这是好事啊"然后让另外三个都接不上话？

每个 Skill 蒸馏自公开著作、书信、传记、访谈与学术评述，经 6 个维度深度调研。激活后，AI 会直接以他们的身份、语气和思维纹路回应你。

## 他们吵过什么

1911 年，阿德勒带人离开弗洛伊德的星期三心理学会，理由是：弗洛伊德坚持性驱力中心论不可妥协，阿德勒认为人不是被裤裆驱动的，是被未来的目标牵引的。

1913 年，荣格在《转化的象征》中把性驱力的"性"含义给淡化了。弗洛伊德认为这是背叛。荣格说："最新发展使我确信我的观点与弗洛伊德主义不可调和。"

一百多年后，峰哥在直播间把弗洛伊德整套理论压缩成一句话："一切精神问题都源于性压抑。" 他管这叫戏称，不叫学术继承。观察者网批评他"消解了问题的严肃性"，他大概会回一句"这是好事啊"。

**一个多世纪的精神分析内战，在这间屋子里继续打。**

## 怎么玩

### 在 TRAE 中使用

把 `skills/` 目录下的文件夹放进 TRAE 的 Skill 目录，然后：

```
帮我用弗洛伊德的视角分析一下我的拖延症
用荣格的角度看看我最近的梦意味着什么
阿德勒会怎么看我的职业选择？
切换到峰哥，帮我看看这事儿
```

**进阶玩法**：让四个人对同一件事发表看法，然后看他们怎么吵起来。

```
我问所有四位：我总是深夜刷手机不想睡，怎么回事？
```

弗洛伊德会追溯你的童年；荣格会找哪个原型被激活了；阿德勒会问这个行为服务于什么目标；峰哥会说"说实话这事儿我也不确定，但下面火急火燎的，心里黄，说出来的话也歪了"。

### 作为独立参考阅读

每个 `SKILL.md` 和调研文件都可独立阅读。心理学三巨头的部分是成体系的思维框架资料，峰哥的部分是当代中文互联网一个独特样本的深度拆解。

## 调研方法

每个 Skill 基于以下 6 个维度的深度调研：

1. **著作与系统思考** — 主要著作的核心论点与论证结构
2. **长对话与即兴思考** — 访谈、播客、书信中的即兴反应
3. **表达DNA** — 句式、词汇、节奏、幽默、引用习惯的风格指纹
4. **外部视角与批评** — 学术界、同行、批评者的评价与反驳
5. **决策记录** — 关键人生决策的动机与后果
6. **人物时间线** — 生平关键节点与思维演变的关联
