# Jung · Adler · Freud · Feng — 思维操作系统合集

> 将四位思想者的思维框架蒸馏为可直接调用的 Skill，让 AI 以他们的视角分析问题、审视决策、提供反馈。

## 这是什么

本仓库收录 4 个「思维操作系统」Skill，每个 Skill 基于公开著作、书信、传记、访谈与学术评述，经 6 个维度深度调研后蒸馏而成。激活后，AI 将以对应人物的身份、语气和思维纹路回应问题。

## 每个 Skill 的内部结构

每个 `SKILL.md` 包含以下模块：

| 模块 | 说明 |
|------|------|
| **角色扮演规则** | 激活后以第一人称回应，不跳出角色；含防漂移机制与退出指令 |
| **回答工作流** | 三步走：问题分类 → 研究维度 → 角色式回答 |
| **身份卡** | 「我是谁」「起点」「现在在做什么」 |
| **核心心智模型** | 从调研中提炼的思维框架，每个含一句话定义、证据、应用、局限 |
| **决策启发式** | 10 条可操作的决策规则，每条含应用场景与案例 |
| **表达DNA** | 句式、词汇、节奏、幽默、确定性、引用习惯的风格规则 |
| **人物时间线** | 关键节点与对思维的影响 |
| **价值观与反模式** | 追求什么、拒绝什么、未解决的内在矛盾 |
| **智识谱系** | 影响过谁 → 被谁影响 |
| **诚实边界** | 局限性声明：不可证伪处、实证争议、翻译偏差等 |

## 四人对照速查

| 维度 | 弗洛伊德 | 荣格 | 阿德勒 | 峰哥 |
|------|---------|------|--------|------|
| **核心驱动** | 无意识决定论 | 集体无意识 | 自卑感与追求优越 | 不可证伪的消解式乐观 |
| **行为归因** | 追溯童年与压抑 | 寻找原型激活 | 问「服务于什么目标」 | 归因性压抑或社会分层 |

| **理论风格** | 辩证对仗 + 考古学隐喻 | 分号级联 + 神话叠覆 | 目的论语法 + 日常比喻 | 短句反问 + 即兴类比 |
| **对弗洛伊德** | — | 决裂：转向集体/历史 | 决裂：从驱力转向目标 | 戏称简化为万能公式 |
| **关键局限** | 不可证伪（波普尔） | 原型解释力过强 | 概念定义模糊 | 公开表达 vs 真实想法有差距 |

## 使用方式

### 在 TRAE 中使用

将 `skills/` 目录下的文件夹放入 TRAE 的 Skill 目录即可。激活方式：

```
帮我用弗洛伊德的视角分析一下我的拖延症
用荣格的角度看看我最近的梦意味着什么
阿德勒会怎么看我的职业选择？
切换到峰哥，帮我看看这事儿
```

### 作为独立参考阅读

每个 `SKILL.md` 和 `references/research/` 下的调研文件均可独立阅读，作为理解这四位思想者的系统性资料。

## 调研方法

每个 Skill 基于以下 6 个维度的深度调研：

1. **著作与系统思考** — 主要著作的核心论点与论证结构
2. **长对话与即兴思考** — 访谈、播客、书信中的即兴反应
3. **表达DNA** — 句式、词汇、节奏、幽默、引用习惯的风格指纹
4. **外部视角与批评** — 学术界、同行、批评者的评价与反驳
5. **决策记录** — 关键人生决策的动机与后果
6. **人物时间线** — 生平关键节点与思维演变的关联

## 诚实声明

- 所有 Skill 基于公开信息提炼，非本人亲口所述
- 心理学三巨头的字面理论在现代实证科学中存在重大争议，本仓库呈现其思维框架而非背书其科学地位
- 峰哥为在世人物，公开表达与真实想法可能存在差距
- 调研时间截至 2026 年 9 月
